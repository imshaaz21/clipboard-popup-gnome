# Screenshots

Actual captures of Clipboard Popup 1.0.0 on GNOME Shell 50, using the dark Adwaita theme and sample clipboard content in an isolated session.

## GNOME Extensions listing

Upload **[gnome-extensions-cover.png](gnome-extensions-cover.png)** as the main listing image (1080 × 840 pixels). It combines actual captures of the pointer popup and top-bar menu with captions; it is not a single desktop screenshot.

The individual PNGs below are available for additional screenshots or closer views. Super+V was assigned for the demonstration; shortcuts are unassigned on fresh installs.

| Image | Shows |
|---|---|
| [GNOME Extensions cover](gnome-extensions-cover.png) | Pointer popup and top-bar menu together |
| [Pointer popup](pointer-popup.png) | Text, an image thumbnail, a favorite, and search |
| [Top-bar menu](top-bar-menu.png) | Pin, preview, delete, private mode, preferences, and clear history |
| [General preferences](preferences-general.png) | History limits, popup appearance, and paste behavior |
| [Privacy preferences](preferences-privacy.png) | Recording, application exclusions, and saved history |
| [Shortcuts preferences](preferences-shortcuts.png) | Key assignments and one-click removal |
| [Shortcut editor](shortcut-editor.png) | Pressing keys to assign a shortcut |
| [About](preferences-about.png) | Version, project page, and bug reporting |

Screenshots use only demonstration text and the project's own logo. They contain no personal clipboard history. They are documentation assets and are not included in the extension ZIP.
